

| **Criterion** | **What to consider** |
| --- | --- |
| Technical feasibility | Can the skills and tools from this course build the main features? Which device features, data, and security needs does it have? |
| Time and cost | Could a small team build a first version in a few months on a modest budget? |
| Audience need | How many people have the problem, and how strongly do they feel it? |
| Competition gap | Is there a clear gap that existing apps leave open? |
| Money or cost recovery | Is there a believable way to cover costs or earn income? |
| Risk | Are there privacy, safety, or store policy risks? |
